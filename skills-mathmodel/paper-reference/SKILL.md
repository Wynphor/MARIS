# Paper Reference: 获奖范文检索

检索匹配的获奖范文并提取风格参考：**$ARGUMENTS**

## Constants

- **DRIVEN_MODEL = `mimo-v2.5`** — 语义匹配 + 结构提取，成本更低
- **PAPER_DB_TYPED = `docs/1.国赛：高教社杯全国大学生数学建模竞赛优秀论文【数学建模老哥】/数学建模典型题目优秀论文/`** — 按题型分类
- **PAPER_DB_YEARLY = `docs/1.国赛：高教社杯全国大学生数学建模竞赛优秀论文【数学建模老哥】/`** — 按年份索引
- **PAPER_DB_LEGACY = `docs/cumcm-past-questions-master/`** — 原有论文库（备用）

## Inputs

1. 赛题类型：优化类 / 评价类 / 预测类 / 机理分析类 / 统计分析类 / 图论网络类
2. 可选：题目关键词（如"环境经济学""交通流"）

## Outputs

输出 `paper_reference_report.md`：

```markdown
# 范文参考报告

## 匹配范文
| 年份 | 题号 | 标题 | 获奖等级 | 匹配度 |
|------|------|------|---------|--------|
| 2020 | C    | 银行对中小微企业的信贷决策分析 | 国一 | 85% |
| 2019 | C    | 机场出租车司机综合决策模型 | 国一 | 78% |

## 结构骨架
1. 问题重述（1-2页，简洁）
2. 模型假设（逐条列出 + 依据说明）
3. 符号说明（三线表）
4. 模型建立与求解（分问题展开）
5. 灵敏度分析（参数扫描 ±20%）
6. 模型评价与改进

## 高分术语表
- 模型构建类："本文建立了...""基于...理论""采用...方法"
- 求解类："通过 XX 求解器...""迭代收敛于...""最优解为..."
- 分析类："灵敏度分析表明...""模型的鲁棒性通过 XX 验证"
- 结论类："结果表明...""相较于 XX 方案...""综合考量..."

## 图表规范参考
- 三线表样式：\toprule / \midrule / \bottomrule
- 配色方案：tab10 / Set2 / colorblind-safe
- 图题：图下方，编号 + 简洁描述
- 表题：表上方，编号 + 简洁描述
```

|------|------|--------|--------|

## Workflow

### Step 1: 确定检索条件

根据 $ARGUMENTS 中的赛题类型，定位典型题目库中的对应目录。如果类型不在上述四类中，则从年度论文库中按关键词检索。

### Step 2: 搜索匹配范文

1. 优先从典型题目库检索（按题型）
2. 若典型库不匹配，从年度库按年份/题号检索
3. 若均不匹配，回退到 `cumcm-past-questions-master/`

### Step 3: 提取结构骨架

浏览 1-2 篇最佳匹配范文的章节组织：
- 问题重述：篇幅、是否分点
- 模型假设：条数、是否有依据说明
- 符号说明：是否用三线表
- 灵敏度分析：是否包含、篇幅占比

### Step 4: 提取术语和图表规范

- 从范文中提取高频术语
- 从范文中提取图表样式特征（三线表、配色、编号格式）

### Step 5: 输出参考报告

生成 `paper_reference_report.md`，供 `paper-write` 注入风格参考。

### Step 6: 自检

- 范文匹配度是否 ≥ 70%？
- 结构骨架是否与实际范文一致？
- 术语表是否来源于范文原文？
- 图表规范是否具体可操作？
