# math_model — 数学建模模型参考书

本目录为数学建模常用模型算法的参考手册，共31章，覆盖竞赛常见题型所需模型。

## 目录结构

- `模型总结/` — 31章PDF，从线性规划到偏最小二乘回归的完整参考
- `国赛/` — 国赛（CUMCM）历年题目参考（2022-2023）
- `美赛/` — 美赛（MCM/ICM）历年题目参考
- `研赛/` — 研究生数学建模竞赛题目参考
- `QUBO模型/` — MathorCup QUBO题型参考
- `题目总结.xlsx` — 模型-题型对照表

## 使用说明

本目录仅供模型查询参考。竞赛时优先查 `模型总结/` 找到对应算法，再配合 AGENTS.md 中的题型-模型映射表选定方案。
