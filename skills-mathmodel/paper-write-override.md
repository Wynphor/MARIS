# 竞赛论文章节模板 — 覆盖 ARIS paper-write 默认结构

当调用 `paper-write` 时，注入此模板覆盖默认的学术论文结构。

## 强制章节顺序

1. 目录
2. 摘要 — 三段式，含≥3个具体数值
3. 问题重述与分析 — 数据概览表（必含）
4. **数据探索与预处理** — 分布图+箱线图+相关热力图+缺失值报告
5. 模型假设
6. 符号说明
7. 模型建立与求解 — **≥3种模型对比** + 公式推导 + 算法伪代码
8. 灵敏度分析 — ≥4维度扫描
9. 模型评价与改进
10. 参考文献 — ≥5条
11. 附录 — **≥8页**（完整代码+中间结果+补充图表）

## 各章节篇幅

| 章节 | 页数 | 必含要素 |
|------|------|---------|
| 问题重述 | 1-2 | 数据概览三线表 |
| 数据探索 | 2-3 | 分布直方图+箱线图+相关性热力图+缺失值报告 |
| 模型假设 | 0.5-1 | 5-8条假设，各附合理性说明 |
| 符号说明 | 0.5-1 | 三线表 |
| 模型建立与求解 | 10-14 | EDA发现→特征工程→**≥3种模型对比表**→公式推导→算法→图表 |
| 灵敏度分析 | 2-3 | ≥4维度（参数+特征+阈值+样本量） |
| 模型评价 | 1-1.5 | 5优+5缺，各附改进方案 |
| 参考文献 | 0.5-1 | ≥5条，[1][2]格式 |
| 附录 | ≥8 | 完整代码+中间结果表+补充图表 |

## 模型建立与求解 — 关键规范

### 模型对比（必须 — 差距最大的地方）

- **至少对比 3 种模型**（如逻辑回归 vs SVM vs 随机森林 vs XGBoost）
- 对比指标≥4个：准确率、精确率、召回率、F1、训练时间
- 三线表呈现，明确标注最优值
- **必须解释选择理由**：不只精度，综合可解释性、计算效率、鲁棒性
- 若最优模型未被选中，必须给出充分理由

### 特征工程（必须）

- 原始字段→衍生特征的完整变换链
- 相关性矩阵 + VIF 共线性检验
- 最终特征统计描述表（均值/标准差/范围）

### EDA 发现（必须）

- 从数据探索提取 3-5 个关键发现
- 每个发现附支撑图表
- 指向后续建模方向

## 竞赛论文深度化与人性化写作规范 (竞赛特供)

### 1. 深度定性与领域专业性 (Anti-Dryness & Domain Narrative)
*   **严禁机械地罗列纯数学公式或单一的算法代码**。必须穿插深刻的行业、经济学、金融学或物理机制等领域背景逻辑，增强论文的“故事感”与学术厚度。
*   **信贷决策案例特供**：必须引入经典经济学（如 **Stiglitz-Weiss 信贷配给理论**）深度剖析信息不对称、道德风险和逆向选择对中小微企业融资瓶颈的系统性根源影响；在特征工程中必须结合微观交易法医学，例如阐述“交易伙伴数（Trade Partner Count）”的供应链抗风险与锁定效应、“作废发票率（Void Invoice Ratio）”的企业合规度与潜在欺诈治理风险；在最优化定价部分必须引入微观经济学“价格弹性差异（Price Elasticity）”（分析优质 A 企业的高议价弹性与劣质 C 企业的刚性流动性饥饿），以经济学逻辑证明风险溢价梯度定价的合理性。

### 2. 人类认知与探索性建模轨迹 (Human Progressive Modeling)
*   **严禁把数学模型写得“一步到位”或“仿佛直接拿到正确答案”**。这不符合人类探索思维，极易被评审判定为无灵性的 AI 模板输出。
*   **必须在论文中还原真实的“试错与探索链”**：
    1.  从朴素的启发式规则（Heuristic Baseline）开始，阐述其粗颗粒度与局限；
    2.  演进到经典的线性模型（如逻辑回归 Logistic Regression），然后剖析在高度非线性的多重共线性发票数据以及厚尾（Fat-tail）分布下，线性拟合的局限与崩溃；
    3.  引入高维投影模型（如支持向量机 SVM，配以 RBF 核函数映射到希尔伯特超空间），阐明如何将非线性分界线性化，并分析超参数选择的鲁棒性瓶颈；
    4.  最终引出基于 Gini 纯度集成的随机森林（Random Forest Ensemble），论证它在解决共线性、多重交互边界和特征缺失时的天然鲁棒性与高维表征能力。

### 3. 高品质 TikZ 矢量图表设计 (TikZ Flowcharts)
*   **第一印象（视觉美感）是获奖的分水岭**。严禁生成简陋的 ASCII 流程图或用低分辨率外部截图充数。
*   **必须在正文中嵌入至少两张基于 LaTeX 原始 TikZ 宏包的矢量块图表**：
    *   **图 1：系统架构与信贷决策流程图 (Decision Flowchart)**：包括数据预处理、多模型风险画像、Lagrangian 利率解耦网格搜索到贪心背包授信额度分配的完整闭环；
    *   **图 2：宏观冲击传导与贝叶斯校正图 (Bayesian Adjust Flowchart)**：直观表达突发宏观灾害（如 COVID-19）如何通过特定行业传染链条改变先验信用风险，并通过贝叶斯后验概率实现重组决策。
*   **TikZ 规范**：使用漂亮的渐变配色（如 `royalblue!80`），圆角矩形节点，清晰的方向箭头，且表格全部使用三线表（用 `booktabs` 宏包的 `\toprule`, `\midrule`, `\bottomrule`），并外包 `\resizebox` 防止溢出物理边界。

### 4. 编译与工具链高可用防御 (Pipeline Reliability & Fallback)
*   由于在 Antigravity 自动化环境中执行 CLI 工具存在调用接口差异（例如 under-the-hood 命令行调用抛出 `run_shell_command not found` 等错误），流水线（Pipeline）必须具备极高容错性。
*   **防御机制**：遇此情况，系统将无缝回退或提醒人工通过标准的 Powershell 原生命令（例如使用 Antigravity 内置的 `run_command` 直接调用本地安装的 `xelatex`）对 `main.tex` 和 `main_article.tex` 进行连续两次的编译，同时调用 `tools/pack_submission.py` 脚本执行 Deterministic 打包。

## 内容充实度检查（10项）

- [ ] 摘要是否含≥3个具体数值？
- [ ] 数据探索是否含≥2张分布图+1张相关热力图？
- [ ] 模型是否对比了≥3种？
- [ ] 对比表是否含≥4个指标？
- [ ] 公式推导链是否完整？
- [ ] 是否含算法伪代码？
- [ ] 正文是否含≥5张图表（必须含至少两幅 TikZ 矢量框图）？
- [ ] 灵敏度是否覆盖≥4维度？
- [ ] 缺点是否附改进方向？
- [ ] 附录是否包含完整无缩水源代码？

## 自检执行规范（生成后强制执行）

论文生成后，必须逐条输出自检报告，格式如下：

```
| # | 检查项 | 状态 | 证据 |
|---|--------|------|------|
| 1 | 摘要≥3数值 | PASS/FAIL | 具体数值列表 |
| 2 | ≥2分布图+热力图 | PASS/FAIL | 图表路径 |
| ... | ... | ... | ... |
```

FAIL 项**必须立即重生成对应章节**。全部 PASS 后论文才能进入审稿阶段。
禁止跳过任何一项。禁止以"基本满足"代替精确判定。

## LaTeX 检查点 & 自动化流程支持

- [ ] **零占位符原则**：严禁出现“此处省略”、“推导略”、“TODO”等词汇。一经发现，管线脚本将自动判定为编译拒收。
- [ ] **表格宽度自适应**：所有表格必须使用三线表。管线脚本会自动确保它们在物理边界内，必要时将自动用 `\resizebox{\textwidth}{!}{...}` 包裹以防溢出。
- [ ] **附录代码自动织入**：求解脚本无需手动贴入 LaTeX。管线脚本会在后处理阶段自动提取 `src/problem_<题号>/` 下的 Python 代码并织入附录 A，保证最终 PDF 和 ZIP 包的代码完整性。
- [ ] 封面已用 pdfpages 插入
- [ ] `\tableofcontents` 在第1页
- [ ] `\setcounter{page}{1}` 在摘要页
- [ ] 参考文献用 `\begin{thebibliography}`
- [ ] 无硬编码身份信息
