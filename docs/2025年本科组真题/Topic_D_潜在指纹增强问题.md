# D题 潜在指纹增强问题

潜在指纹一般指在犯罪现场的物体表面上提取到的指纹，刑侦人员将采集到的潜在指纹与指纹库中的指纹进行比对，以确定犯罪嫌疑人身份。在很多命案中，潜在指纹是仅有的线索，由于潜在指纹具有脊结构不清楚、局部区域质量差的特点，可提取的特征较少，识别精度低，因此需要进行潜在指纹增强，即将低质量的潜在指纹转化为高质量的指纹，从视觉效果上讲，增强后的指纹脊结构清楚，断裂被修复，细节点清晰；从识别精度上讲，增强后的指纹与库指纹匹配时，识别精度提高。由于视觉效果过于主观，将识别精度作为本题目的主要评价手段。

假设潜在指纹空间为 X，库指纹空间为 Y，给定匹配器，潜在指纹的匹配过程可以表示为映射 F: X, Y → [0, 1]，区间[0, 1]为归一化的匹配分数，匹配分数越接近 1 则认为两个指纹越相似。识别一个潜在指纹 $x_0$ 时，需要计算 $x_0$ 与所有库指纹的匹配分数，即集合 S = {F($x_0, y_0$) | ∀ $y \in Y$}。给定整数 n，将 S 中的分数从大到小排序，若与 $x_0$ 对应的库指纹 $y_0$ 的匹配分数 F($x_0, y_0$) 出现在前 n 位，则认为成功识别 $x_0$。X 中成功识别的元素数占总数的比称为 rank-n 识别率，记为 R(X, Y, n, F)。指纹增强过程即求一映射 G，满足 R(G(X), Y, n, F) > R(X, Y, n, F)，rank-n 识别率提高程度 R(G(X), Y, n, F) - R(X, Y, n, F) 可以用来评价增强的好坏；由于 R(X, Y, n, F) 在给定匹配器和 n 时为常数，因此可以考虑 max R(G(X), Y, n, F)。

MOLF（Multi-sensor Optical And Latent Fingerprint Database）数据集是目前潜在指纹增强研究的基准数据集之一，包括潜在指纹和库指纹，其中潜在指纹是使用黑色粉末提取到的陶瓷片上的指纹，库指纹是使用不同传感器采集的指纹。该问题从 MOLF 数据集的 4400 张潜在指纹中选取了 720 张（见附件），并选取了质量最好的 Cross Match L-Scan Patrol 光学传感器数据子集的指纹作为库指纹。这 720 个指纹对被分为训练集（600）和测试集（120）。

**附件说明：**
- Example Data 文件夹包含 600 张潜在指纹图像及其对应的库指纹；
- Identification Software 文件夹是指纹识别软件，参赛选手设计算法增强 Example Data 的潜在指纹，并使用识别软件将增强后的指纹与 Example Data 的库指纹进行匹配，计算识别精度，验证算法的有效性。
- Test Latent 文件夹包含 120 张与 Example Data 的指纹不同的潜在指纹图。
