# 论文撰写与 LaTeX 模板原始资料

## 1. 论文摘要 (Abstract) 深度要求
*   **三段式结构**：
    1.  开头：背景+目标。
    2.  主体：模型名称 + 核心算法 + 求解结果（含硬数据）。
    3.  结尾：亮点、创新点、灵敏度分析结论。
*   **禁忌**：严禁第一人称（用"本文"）、严禁公式/图表入摘要、严禁废话。

## 2. 逻辑结构

> ⚠️ **国赛与省赛规则不同**：国赛（CUMCM）自2019年起明确不需要目录页。但**山东省赛要求第1页为目录、第2页为摘要专用页**（详见 AGENTS.md 和竞赛章程 PDF）。

*   国赛（CUMCM）2019年起明确**不需要目录页**。
*   山东省赛强制结构：目录页 → 摘要专用页 → 正文（第3页起）。
*   一级标题规范（省赛适用）：
    1. 问题重述
    2. 模型假设
    3. 符号说明 (三线表)
    4. 模型的建立与求解 (基于XX模型的问题一求解)
    5. 模型检验与灵敏度分析 (高分项)
    6. 模型评价与推广

## 3. LaTeX 模板资源
*   **核心模板**：`cumcmthesis` (LaTeXStudio 维护)。
*   **GitHub**: [https://github.com/latexstudio/CUMCMThesis](https://github.com/latexstudio/CUMCMThesis)
*   **微调建议**：
    *   使用 `pdfpages` 宏包插入官方 Word 转出的 PDF 封面。
    *   公式使用 `amsmath` 环境，严禁截图。
    *   参考文献遵守 GB/T 7714 标准。

## 4. 可视化标准
*   流程图：Visio/ProcessOn (拒绝手绘感)。
*   数据图：Matplotlib/Origin (配色专业，拒绝 Excel 默认色)。
*   表格：全篇统一采用**三线表**。
