# Problem Decompose: 赛题拆解

将数学建模赛题分解为结构化子问题清单：**$ARGUMENTS**

## Constants

- **DRIVEN_MODEL = `deepseek-v4-pro`** — 需要深度语义理解赛题文本
- **OUTPUT_FILE = `problem_decomposition.md`** — 输出文件，供下游 `model-select` 消费

## Inputs

1. 赛题 PDF 文件路径，或直接粘贴的题目描述文本
2. 可选：数据附件（xlsx/csv），自动探测数据维度和字段

## Outputs

输出 `problem_decomposition.md`，结构如下：

```markdown
# 赛题拆解报告

## 题目概述
[1-2 段概述题目背景和总体目标]

## 子问题清单

### 子问题 1: [名称]
- **类型**: 优化类 / 评价类 / 预测类 / 机理分析类 / 统计分析类 / 图论网络类
- **约束条件**:
  1. ...
  2. ...
- **优化目标**（如有）: ...
- **已知数据**:
  - 数据文件: ...
  - 关键字段: ...
  - 数据量: ...

### 子问题 2: [名称]
...

## 子问题依赖关系
[子问题间的先后依赖，如有则标注]
```

## Workflow

### Step 1: 读取赛题

- 若 `$ARGUMENTS` 为 PDF 路径，读取 PDF 全文
- 若为纯文本，直接使用
- 若提供数据附件，读取前 50 行了解字段结构和数据量
- **ARIS 调用**: 同时调用 `research-lit` 搜索类似赛题的学术文献，调用 `exa-search` / `gemini-search` 搜索赛题背景资料和行业数据源，辅助 Step 2 对题目的理解

### Step 2: 提取题目结构

1. 识别题目中明确的问题数量（通常用序号或"问题一/二/三"标注）
2. 提取每个问题的核心目标（最大化/最小化/评价/预测/模拟）、显式约束条件、引用的数据

### Step 3: 判定子问题类型

按以下特征信号分类：

| 特征信号 | 判定类型 |
|---------|---------|
| 含"最大/最小/最优/分配/调度/路径" | 优化类 |
| 含"评价/排名/综合评估/优劣/等级" | 评价类 |
| 含"预测/预报/趋势/未来/演变" | 预测类 |
| 含"机理/过程/物理/化学/生物/传导" | 机理分析类 |
| 含"分析/相关性/因素/影响/显著性" | 统计分析类 |
| 含"图/网络/流/连通/最短路径" | 图论网络类 |

### Step 4: 输出结构化报告

按 Outputs 模板生成 `problem_decomposition.md`，确保每个子问题包含完整的类型、约束、目标和数据描述。

### Step 5: 自检

- 每个子问题是否有明确的求解方向？
- 数据需求是否与提供的附件匹配？
- 子问题间依赖关系是否合理？
- 类型判定是否正确？（对照特征信号表复核）
