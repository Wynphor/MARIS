# Contest Format Check: 竞赛格式适配

检查论文是否符合竞赛格式要求：**$ARGUMENTS**

## Constants

- **DRIVEN_MODEL = `mimo-v2.5`** — 格式检查，成本低
- **CHECKLIST = 省赛格式规则** — 基于 `docs/` 下的章程和参赛规则

## Inputs

1. 论文 PDF 或 LaTeX 源文件路径

## Outputs

输出 `format_check_report.md`：

```markdown
# 竞赛格式检查报告

## 总体结果: ✅ 通过 / ❌ 不通过

## 逐项检查

| 检查项 | 要求 | 实际 | 结果 |
|--------|------|------|------|
| 目录页 | 第1页为目录 | ✅ | ✅ |
| 摘要分页 | 单独一页，不超过一页 | ✅ | ✅ |
| 正文页数 | ≤20页 | 18页 | ✅ |
| 参考文献标注 | 正文用[1][2]标注 | ✅ | ✅ |
| 身份信息 | 不得出现学校/姓名 | ✅ | ✅ |

## 需修改项
- [ ] 第5页表格中存在竖线（应使用三线表）
- [ ] 参考文献第3条格式不完整
```

## 竞赛格式检查清单

基于山东省大学生数学建模竞赛规则：

| # | 检查项 | 合规标准 | 严重度 |
|---|--------|---------|--------|
| 1 | 目录 | 第1页，含所有章节标题及页码 | 🔴 强制 |
| 2 | 摘要分页 | 单独占第2页，不超过一页 | 🔴 强制 |
| 3 | 正文页数 | ≤ 20 页（从第3页起算） | 🔴 强制 |
| 4 | 参考文献 | 正文引用处用[1][2]标注，按引用次序列出 | 🔴 强制 |
| 5 | 身份信息 | 正文和附录不得出现学校、姓名等 | 🔴 强制 |
| 6 | 附录 | 可放完整数据表、代码片段、补充图表 | 🟡 建议 |
| 7 | 三线表 | 全篇表格统一使用三线表（\toprule/\midrule/\bottomrule） | 🟡 建议 |
| 8 | 图表编号 | 图和表分别编号，标题居图下方/表上方 | 🟡 建议 |
| 9 | 公式编号 | 重要公式右对齐编号 | 🟢 可选 |
| 10 | 页眉页脚 | 不得出现个人信息 | 🟡 建议 |

## Workflow

### Step 1: 读取论文

- 若输入为 `.tex` 文件：直接读取 LaTeX 源码
- 若输入为 PDF：提取文本和页面数

### Step 2: 结构检查

逐项对照检查清单，重点关注：
1. 目录是否在第 1 页？用 `\tableofcontents` 是否正确？
2. 摘要是否单独一页？`\begin{abstract}` 前后是否有 `\newpage`？
3. 正文总页数是否 ≤ 20？
4. 参考文献是否用 `\begin{thebibliography}` 并按 `[1]` 格式？

### Step 3: 格式检查

1. LaTeX 源码中搜索 `\midrule` 确认三线表使用
2. 搜索学号/姓名/学校等关键词，确认身份信息已屏蔽
3. 检查 `\label` 和 `\ref` 是否有未定义引用
4. 检查是否有超过页边距的表格或图片

### Step 4: 输出报告

生成格式化的检查报告，区分：
- 🔴 强制项：不通过则必须修改
- 🟡 建议项：影响印象分
- 🟢 可选项：锦上添花

### Step 5: 自检建议

如果检查不通过，给出具体的修改建议：
- "第 5 页 `\begin{tabular}{|c|c|}` 应改为 `\begin{tabular}{cc}` 并添加 `\toprule`/`\midrule`/`\bottomrule`"
- "`\author{张三}` 应在提交前替换为占位符"
